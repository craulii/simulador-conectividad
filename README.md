# Simulador de Conectividad

Simulador de cobertura y conectividad de redes sobre un planeta 3D, construido con React, TypeScript, Vite y React Three Fiber. Proyecto de demostracion de Ingenieria Civil Telematica, en construccion por etapas.

Documentacion completa (arquitectura, uso, despliegue) pendiente hasta el cierre de la etapa final del proyecto.

## Desarrollo local

```
npm install
npm run dev
```

## Build de produccion

```
npm run build
```
